# 05: 3D Tilt Case Study Showcase with Problem-Solution-Impact Tabs

**What to build:** An interactive flagship portfolio showcase featuring 3D tilt physics and spotlight card effects. Replaces basic screenshot cards with structured case study cards for Bubo AI, Maviance Payment Gateway, Warap Work, and AfricaFix. Visitors can filter projects by category (All, AI, Fintech, Mobile) and interact with cards via 3D parallax tilt on mouse move. Clicking a case study expands into an interactive tabbed view detailing the business Problem, architectural Solution, Tech Stack tags, live demo/repo links, and measurable Impact Metrics (e.g., query latency, transaction throughput).
